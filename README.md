> **الاسم المقترح لمستودع GitHub (Repository Name):**

## 📌 نبذة عن الكورس (Overview)
يُعد هذا المستودع مرجعاً شاملاً ومُلخصاً عملياً لغرفة **Web Application Basics** المقدمة من منصة **TryHackMe**. يهدف الكورس إلى بناء أساس متين في فهم كيفية عمل تطبيقات الويب من الداخل، وآلية التواصل بين العميل (المتصفح) والخادم (Server)، مما يُعد حجر الأساس للانطلاق في مجالات **الأمن السيبراني (Cybersecurity)**، **اختبار اختراق تطبيقات الويب (Web Penetration Testing)**، أو **تطوير الويب (Web Development)**.

---

## 🎯 أهداف التعلم (Learning Objectives)
بنهاية هذا الكورس، ستكون قادراً على:
- فهم ماهية تطبيق الويب وكيفية عمله وتشغيله داخل متصفح الويب.
- تحليل مكونات عنوان **URL** بالتفصيل وفهم دور كل جزء والمخاطر الأمنية المرتبطة به.
- التعرف على آلية عمل **طلبات واستجابات HTTP (HTTP Requests & Responses)** وبنية الرسائل.
- التمييز بين الأنواع المختلفة لأساليب طلب HTTP (**HTTP Request Methods** مثل `GET`, `POST`).
- فهم معاني **رموز استجابة HTTP (HTTP Status Codes)** ودلالاتها (مثل `200`, `404`, `500`).
- إدراك كيفية عمل **رؤوس HTTP (HTTP Headers)** وأهميتها البالغة في تأمين الاتصال وحماية البيانات.

## 🛠️ الأدوات والمفاهيم الأساسية المغطاة
* **البروتوكولات:** `HTTP` / `HTTPS`
* **البنية التحتية للويب:** `Web Browser`, `Web Server`, `WAF (Web Application Firewall)`
* **أمن المعلومات:** `Typosquatting`, `Phishing`, `Input Sanitization`, `Injection Prevention`
